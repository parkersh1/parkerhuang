Hashtagify

Web app • React, Firebase, Spotify API

Hashtagify helps listeners discover music by adding user-generated tags to playlists, so recommendations feel more transparent and easier to control. I built a web app where users can log in, upload or connect playlists, and browse tagged tracks and community playlists through a clean search and filtering experience. On the backend, I implemented Firebase authentication and structured data storage so tags, playlists, and users stay consistent and reliable. Next, I want to evaluate impact by tracking usage metrics like tag adoption rate, searches per session, and whether tagged browsing leads to more saves or follows.

  • Built playlist upload + tagging and a tag-first browsing flow for discovery
  • Implemented Firebase auth and data model to support users, playlists, and tags

Fashion Review Sentiment Tracker

Data analysis • Python, VADER, Excel

This project analyzes fashion show reviews from 2018–2024 to understand how critical reception changes over time across major designers. I collected and cleaned review text, then used VADER sentiment scoring in Python to quantify tone at scale and make year-over-year comparisons. I summarized results in Excel with charts and tables that highlight shifts in sentiment and differences between brands or seasons. If I extend this, I would validate accuracy by spot-checking samples, comparing VADER to another model, and testing whether sentiment changes align with known creative-director or collection changes.

  • Cleaned review text and computed sentiment scores with VADER in Python
  • Visualized trends in Excel to compare designers and time periods

Zinnia All Day (Capstone)

Product + UX • Research, Prototyping, Data Analysis

Capstone project with Zinnia TV to help dementia caregivers schedule daily video content in a way that supports routine and reduces distress. As a team, we researched caregiver routines and validated that late-day transitions are often the hardest and that caregivers prefer guided control over fully manual scheduling. We designed “Zinnia All Day,” a drag-and-drop Schedule Builder with time-of-day structure, curated content, and quick playlists for flexible moments.

  • Team: Turned research into personas + validated concepts, then iterated on the Schedule Builder interaction model and key screens based on feedback.
  • Me: Synthesized survey/interview results into product requirements and success metrics (ex: time to build a schedule, number of edits needed, perceived effort).
  • Me: Built the prototype’s simulated scheduling backend (schedule schema + mock data) to support realistic demos and spring usability testing.
